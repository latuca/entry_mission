|---|---|---|---|
| AI 검토 1: 저장 기능이 없다 | 카드를 B칸·C칸으로 옮긴 뒤 새로고침했더니 8편이 모두 미분류로 돌아갔다. 브라우저 저장소(localStorage)에도 저장된 값이 없었다. | 반영 | 기획서 완성 기준 '같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다'에 어긋난다. 내 셀프 피드백과도 같다. |
| AI 검토 2: '처음으로'가 직접 추가한 영화를 지우지 않는다 | '내가추가'를 만들고 타이타닉을 A칸으로 옮긴 뒤 '처음으로'를 눌렀더니 8편이 모두 미분류로 돌아갔고, '내가추가' 카드도 사라졌다. | 보류 | AI 설명과 실제 동작이 다르다. 기획서 '처음 영화 목록과 배치로 돌아갑니다'대로 동작하고 있어 고칠 부분이 없다. |
| AI 검토 3: 빈 제목을 막지 않는다 | 입력창을 비운 채, 그리고 띄어쓰기만 넣고 '추가'를 눌렀더니 글자 없는 카드가 생겼고 안내 문구가 '‘’를 추가했어요.'로 나왔다. 빈 카드를 지울 방법은 '처음으로'밖에 없다. | 반영 | 기획서는 '제목을 입력하면 새 영화 카드가 생깁니다'라고 했다. 입력하지 않은 경우는 기획서에 없지만, 영화가 아닌 빈 카드가 남는 것은 쓰다가 이상한 점이다. |
| AI 검토 4: 세 가지 외에는 완성 기준을 잘 지키고 있다 | 화면 폭을 390px로 줄여 열었더니 제목과 입력창이 오른쪽에서 잘리고, '추가'·'처음으로' 버튼은 화면 밖에 있었다. 페이지 폭이 960px로 고정되어 있었다. | 보류 | AI의 이 판단은 사실과 다르다. 완성 기준 '화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다'를 지키지 못한다. 이 문제는 아래 동료의 휴대폰 의견에서 반영한다. |
| 동료: 휴대폰으로 열어 보니 불편했다 | 위와 같이 390px 폭에서 오른쪽이 잘리고 버튼이 화면 밖에 있었다. (휴대폰 터치 이동은 에뮬레이션에서 카드 탭이 다른 요소에 가로막혀 확인하지 못했다.) | 반영 | 완성 기준 4번과 정확히 맞닿는다. '불편'의 원인으로 가장 큰 것이 폭 고정이라고 직접 확인했다. |
| 동료: 카드 옮기는 게 처음엔 헷갈렸다 | 컴퓨터 화면에서 '카드 클릭 → S 글자 클릭'과 '카드 끌기' 모두 정상 동작했다. 다만 카드를 고른 뒤 S칸의 빈 곳을 눌렀을 때는 아무 일도 일어나지 않았고, 안내 문구는 '놓을 등급을 누르세요.'였다. | 되묻기 | 어느 방식(클릭·끌기)으로, 어느 단계에서 헷갈렸는지 알 수 없어 확정할 수 없다. |
| 동료: 끌어서 옮기기 불편하다. 안 정한 영화가 맨 아래라 S칸까지 끌려면 화면을 올려야 한다. 영화 목록이 위나 옆에 있으면 좋겠다 | 1280×900 화면에서 S칸은 위에서 312px, '아직 안 정한 영화' 영역은 1043px에서 시작해서 한 화면에 함께 보이지 않았다. 끌어서 옮기는 동작 자체는 됐다. | 보류 | 기획서가 '위에 S·A·B·C 칸, 아래에 아직 안 정한 영화 카드'로 배치를 정해 두어 의견과 부딪힌다. 카드를 누르고 등급 글자를 누르는 대안도 이미 있다. 배치를 바꾸려면 기획서부터 고쳐야 해서 지금은 보류한다. |
| 동료: 카드 색이 칙칙하다 | 카드는 회색 계열 그라데이션(#e6e6e3 → #cfcfcb)이었고 흰 칸 위에서 차분했다. | 보류 | 취향 문제이고 기획서에 색 조건이 없어 꼭 바꿀 이유가 없다. |
| 동료: 영화 포스터 사진이 나오면 좋겠다 | 카드에 이미지(img)는 하나도 없고 제목 글자만 있었다. | 보류 | 기획서 '외부 파일이나 로그인 없이 HTML 한 장으로 열립니다'와 부딪힌다. '필요한 자료'도 영화 제목 8개뿐이다. 영화 이미지 들어가면 저작권 문제가 있을 수 있다. |
| 동료: C칸은 없어도 될 것 같다 | S·A·B·C 네 칸이 있고 C칸 이름은 '아쉬움'이었다. | 보류 | 기획서가 'S·A·B·C 등급'으로 나누는 것을 목적으로 적었다. |
| 동료: 큰 문제는 없어서 PASS | 위 확인에서 완성 기준 두 개(새로고침 후 유지, 좁은 화면)가 지켜지지 않았다. | 보류 | PASS의 근거가 사실과 다르다. 다만 좋다고 한 부분(아래)은 직접 해 보니 맞았다. |

동료가 좋았다고 한 점 세 가지도 직접 확인했고 모두 사실이었다 (표에서는 제외).
- 등급마다 색이 달랐다 (S 빨강, A 주황, B 초록, C 파랑).
- 위쪽에 '8편 중 0편 나눔'처럼 진행 상황이 나오고, 카드를 옮기면 숫자가 바뀌었다.
- 끌어서 칸 위에 올리면 칸 배경색이 연한 베이지로 바뀌었다 (is-over 상태 확인). 다만 흰색과의 차이가 작아 눈에 덜 띌 수 있다.

- 아무도 말하지 않았는데 내가 찾은 것:
  - 같은 제목을 중복으로 추가할 수 있다: '올드보이'를 두 번 추가했더니 같은 이름의 카드가 두 장 생겼다. 두 장을 서로 다른 칸에 놓을 수도 있어서 '영화가 한 칸에만 있고'라는 기준의 취지와 어긋난다.
  - 카드 클릭 이동의 안내가 모호하다: 내 셀프 피드백에는 '클릭이벤트는 안 먹힘'이라고 적었는데, 다시 해 보니 '카드 클릭 → 등급 글자(S·A·B·C) 클릭'은 정상 동작했다. 안 됐던 것은 등급 칸의 빈 곳을 누르는 경우였고, 안내 문구('놓을 등급을 누르세요.')가 글자를 눌러야 한다는 점을 알려 주지 않는다.
  - 좁은 화면 문제의 원인: 동료는 '휴대폰이 불편했다'까지만 말했고 AI는 문제없다고 했다. 직접 확인한 원인은 페이지 폭이 960px로 고정되어 있다는 점이다.

## 셀프 피드백

* 제목 입력하면 새 영화 카드 나타나지만, 중복된 경우 생성 못하게 막는 기능이 없음.
* 같은 파일 다시 열면 초기화되어 있음.
* 화면 폭 좁아질 경우, 오른쪽 잘림. 
* 드래그 앤 드랍은 되지만, 클릭이벤트는 안 먹힘.
