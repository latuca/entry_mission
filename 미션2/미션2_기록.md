# 미션 2 기록

- 사용한 AI 이름 / 주요 대화 캡처 파일명: Claude (Sonnet 5.5) / (캡처 파일명은 직접 적어 주세요)
  - 대화에 올린 파일: 기획서.md, 영화_수정전.html
  - 받은 파일: 영화_수정후.html
- 좁혀서 적은 한 문장: 기존 영화 8개 중 제목에 띄어쓰기가 있는 3개(센과 치히로의 행방불명, 어벤져스: 엔드게임, 토이 스토리)와 새로 추가한 영화는 클릭으로도 끌어 놓기로도 등급 칸에 옮겨지지 않고, 띄어쓰기 없는 5개는 모두 정상이다.
- 좁히려고 해 본 것과 결과:
  - 기존 영화 8개를 모두 클릭과 끌어 놓기로 옮겨 봄 → 5개는 모든 등급에서 잘 되고, 3개는 두 방식 모두 안 됨. 안 되는 3개는 모두 제목에 띄어쓰기가 있음.
  - 제목을 입력해 새 영화를 추가해 봄 → 카드는 생기지만 새 영화도 옮겨지지 않음.
  - 나머지 완성 기준(저장, 처음으로, 좁은 화면, 빈 입력 안내 등)은 모두 정상이라, 문제는 "카드를 옮기는 부분"으로 좁혀짐.
  - 되는 것과 안 되는 것의 차이는 스스로 알지 못해서 AI에게 물어봄.
- AI가 말한 원인과, 그 설명을 직접 확인한 결과:
  - AI가 말한 원인: 카드를 만드는 코드가 `data-id=` 뒤에 따옴표 없이 제목을 끼워 넣어서, 브라우저가 첫 번째 띄어쓰기에서 값을 끊어 읽음. 예를 들어 `센과 치히로의 행방불명`은 `센과`로 잘림. 잘린 id는 영화 목록에 없어서 코드가 에러 없이 조용히 멈추기 때문에, 띄어쓰기가 있는 제목만 안 옮겨짐.
  - AI가 알려 준 확인 방법: (1) 카드를 우클릭해 검사에서 `data-id` 확인, (2) 콘솔에서 `[...document.querySelectorAll('.card')].map(c => c.textContent + ' → ' + c.dataset.id)` 실행, (3) 띄어쓰기 없는 제목과 있는 제목을 각각 추가해 비교. (직접 해 본 결과는 여기에 적어 주세요)
  - 수정 후 확인: 기존 영화 3개가 정상적으로 옮겨짐을 직접 확인함. 원인 설명이 맞았다고 볼 수 있음.
  - 추가로 생긴 문제: 미리보기 안에서 "테스트 둘" 추가가 안 됨. AI의 첫 추측(이미 같은 제목이 저장돼 있어서)은 스크린샷과 맞지 않아 틀렸음. 스크린샷의 안내 문구가 `처음 목록으로 돌아왔어요.` 그대로인 것이 단서였고, 진짜 원인은 미리보기 창이 폼 제출을 막아서 `추가` 버튼의 코드가 실행되지 않는 것이었음. AI가 Chrome으로 재현해 확인함: 미리보기처럼 폼 제출을 막으면 안 되고, 허용하면 됨. HTML 파일을 크롬에서 직접 열면 공백 있는 제목과 없는 제목 모두 추가·이동·새로고침 후 저장이 정상.
