# 영화 티어리스트 웹페이지 기획서

## 1. 누가 쓰나

- 안영찬 님이 만들고, 친구들이 각자 자기 브라우저에서 직접 자기 티어리스트를 짭니다.
- 불특정 다수에게 공개하는 용도는 아닙니다. 링크를 받은 친구들끼리 씁니다.
- 별도 서버는 운영하지 않습니다. HTML 파일 하나를 만들어 링크로 공유합니다.
- 친구의 결과가 안영찬 님에게 전달되거나 기기 간에 이어지지는 않습니다. 저장은 각자 브라우저 안에서만 이뤄집니다.
- 파일을 올려 링크로 만드는 방법(호스팅): 깃허브
- 지원할 기기·브라우저 범위: chrome, pc만.

## 2. 무엇을 하려고

- 친구들과 영화 이야기를 할 때 화면을 띄워 놓고, 내가 본 영화를 등급별로 나눈 결과를 직접 보여주며 대화 소재로 삼으려고 합니다.
- 결과를 보여주는 것이 핵심이라 큰 화면에서 한눈에 읽히는 것이 중요합니다.

## 3. 화면과 동작

**분위기**
- 크리스마스에 벽난로 앞에 둘러앉아 대화하는 cozy한 느낌입니다.
- 따뜻한 갈색 나무 톤에 와인색, 전나무 초록, 호박색 불빛을 씁니다. (대화에서 제안하고 진행한 방향)
- 등급별 색상, 글꼴, 세부 레이아웃: 자율

**등급**
- S / A / B / C 4단계입니다.

**영화 카드**
- 포스터 이미지가 들어간 카드입니다.
- 실제 포스터는 쓰지 않고, 저작권 문제가 없도록 제가 만든 대체 이미지를 넣습니다.
- 카드에 제목을 함께 적습니다.
- 대체 이미지의 구체적인 그림 스타일: 자율.

**영화 옮기기**
- PC에서는 카드를 끌어서 등급 줄에 놓습니다.
- 휴대폰에서는 카드를 눌러 선택한 뒤 등급 버튼을 누릅니다.
- 두 방식을 모두 지원합니다.

**영화 추가·제거**
- 기본 8편에 더해 친구들이 영화를 추가할 수 있습니다.
- 추가한 영화는 포스터 대신 기본 색상 카드로 표시됩니다.
- 영화를 뺄 수도 있습니다.
- 추가할 때 입력하는 항목(제목만 받을지 등), 같은 제목 중복 처리: 같은 제목 못하게
- 영화를 뺄 때 확인 창을 띄울지: 없음

**저장과 초기화**
- 배치는 각자 브라우저에 자동 저장되어, 다시 열어도 남아 있습니다.
- "처음부터 다시" 버튼으로 초기화할 수 있고, 누르기 전에 확인 창을 띄웁니다.
- 초기화하면 기본 8편이 모두 돌아오는지(뺀 영화 복원, 추가한 영화 삭제 여부): 가능하게
- 영화를 뺀 상태와 추가한 영화가 새로고침 후에도 유지되는지: 가능하게

**이미지 저장**
- "이미지로 저장" 버튼을 눌러 티어리스트를 PNG로 내려받습니다.
- 이미지에 포함할 범위(티어리스트 부분만 할지, 제목·장식을 넣을지): 제목-장식까지 넣어서

## 4. 필요한 자료

**기본 영화 8편**
1. 기생충
2. 인터스텔라
3. 라라랜드
4. 센과 치히로의 행방불명
5. 어벤져스: 엔드게임
6. 범죄도시
7. 타이타닉
8. 토이 스토리

**이미지**
- 영화 8편 각각의 원본 대체 이미지는 제가 만듭니다. 별도로 받을 자료는 없습니다.

## 5. 완성 기준

만든 뒤 하나씩 직접 확인할 체크리스트입니다.

- [ ] 휴대폰에서 끌기 없이 선택 방식만으로 8편을 모두 등급에 옮길 수 있다.
- [ ] PC에서 끌어서 놓기로 8편을 옮길 수 있다.
- [ ] 새로고침해도 배치가 남고, "처음부터 다시"를 누르면 확인 후 초기화된다.
- [ ] 영화를 추가하면 기본 색상 카드로 나타나고, 새로고침 후에도 남는다.
- [ ] 영화를 뺄 수 있다.
- [ ] "이미지로 저장"을 누르면 티어리스트가 PNG로 내려받아진다.
- [ ] 큰 화면(노트북이나 TV)에 띄웠을 때 멀리서도 제목과 등급이 읽힌다.
