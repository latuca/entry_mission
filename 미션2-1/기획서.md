# 기획서: UAM 소개 페이지 "We Fly the Dream"

> 작성: AI와의 질의응답으로 초안 작성 후, 작성자가 검토·수정 (아래 "11. 사용한 AI 서비스와 모델" 참고)
> 상태: 초안 (작성자 검토 전)

## 1. 대상 사용자

- **주된 사용자:** 작성자 본인 (창업 아이템인 UAM을 소개하는 용도)
- **방문자:** 불특정 다수. UAM을 처음 접하거나 이름만 들어본 사람
- **사용 상황:** 링크를 열어 스크롤하며 UAM이 무엇이고 어떤 가치가 있는지 한 번에 이해한다. 전문 지식은 필요하지 않다.

## 2. 사용 목적

한국에서는 아직 상업화 전이고 안전 규제도 있어서 접하기 어려운 UAM(도심항공교통)을 쉽게 소개한다. 방문자가 다음 세 가지를 이해하는 것이 목적이다.

1. UAM으로 어떤 수익 모델을 만들 수 있는가
2. UAM이 실생활에 어떤 도움을 주는가
3. UAM이 사회적 약자에게 어떤 도움을 줄 수 있는가

방문자가 열자마자 가장 먼저 확인할 내용은 첫 문장이다.

> **We Fly the Dream: 우리는 도시의 지도를 바꿉니다.**

## 3. 화면 구성과 동작

### 3-1. 디자인 방향

- **분위기:** 미래지향적이고 시각적 자극이 있는 풀스크린 구성. 큰 문장 중심, 한 화면에 한 메시지.
- **색상 (초안):** 짙은 남색~검정 배경(`#050B18`)에 차갑고 시원한 포인트 색. 청록(`#22D3EE`), 하늘색(`#7DD3FC`), 얼음빛 흰색(`#E6F4FF`). 따뜻한 색은 쓰지 않는다.
- **레퍼런스에서 가져올 요소:** 글자 등장 효과, 배경 전환, 큰 문장 중심 구성. (레퍼런스의 색상, 사진, 문구는 가져오지 않는다.)

### 3-2. 섹션 구성 (동등한 비중)

| 순서 | 섹션 | 큰 문장 (초안) | 배경 |
|---|---|---|---|
| 1 | 첫 화면 | We Fly the Dream: 우리는 도시의 지도를 바꿉니다. | 짙은 남색 + 야간 도시 위를 나는 UAM 기체 |
| 2 | UAM이란? 지금 어디까지 왔나 | 하늘이 새로운 도로가 됩니다. | 도시 야경, 기체 실루엣 |
| 3 | 수익 모델 | 하늘에서 새로운 사업이 시작됩니다. | 청록 계열 |
| 4 | 실생활 도움 | 이동 시간이 줄면, 하루가 달라집니다. | 하늘색 계열 |
| 5 | 사회적 약자 지원 | 닿기 어려웠던 곳까지, 하늘이 이어줍니다. | 밝은 푸른빛 |
| 6 | 마무리와 출처 | 도시의 지도는 다시 그려집니다. | 다시 어두운 배경 |

세 주제(섹션 3~5)는 같은 높이와 분량으로 배치한다.

### 3-3. 섹션별 내용 (소개 수준, 깊이 들어가지 않는다)

- **섹션 2:** UAM이 무엇인지 한두 문장으로 설명한다. 한국에서는 아직 상업 운항 전이며 안전 기준을 갖추는 단계라는 점만 짧게 언급한다. 규제 조항, 인증 절차, 법령 이름 같은 세부 내용은 적지 않는다.
- **섹션 3 (수익 모델):** 카드 3~4개 수준. 예: 도심 이동 서비스, 관광·레저 노선, 응급·물류 운송, 기체 운영·정비·이착륙 시설 같은 연계 사업. 구체적인 금액이나 시장 규모 수치는 넣지 않는다.
- **섹션 4 (실생활 도움):** 이동 시간 단축, 교통 혼잡 우회, 접근하기 어려운 지역과의 연결 등을 짧은 문장으로 소개한다.
- **섹션 5 (사회적 약자 지원):** 교통이 불편한 지역의 주민, 이동이 어려운 고령자·장애인, 응급 환자 이송 등 도움이 될 수 있는 사례를 소개한다. 단정적 표현 대신 "가능성"으로 서술한다.

### 3-4. 동작

- 페이지를 열면 첫 문장이 글자 단위로 차례로 나타난다.
- 스크롤하여 다음 섹션에 들어가면 큰 문장이 아래에서 떠오르며 나타나고, 배경이 부드럽게 전환된다.
- 화면 한쪽에 현재 섹션을 보여주는 점 내비게이션이 있고, 점을 누르면 해당 섹션으로 이동한다.
- 모바일과 데스크톱 모두 같은 흐름으로 보인다.
- 운영체제의 "동작 줄이기" 설정을 켠 방문자에게는 글자 등장·배경 전환 애니메이션을 생략하고 내용을 바로 보여준다.

## 4. 필요한 자료

### 4-1. 배경 이미지

- **기본 방식(A): 코드로 직접 그린 이미지.** CSS와 SVG로 UAM 기체와 도시 야경을 그린다. 출처와 사용 권한 문제가 없고, 다른 파일 없이 열린다.
- **사실감 지침 (HTML 제작 단계에서 Opus 5.5에게 전달):**
  - 최대한 사실적이되 미래지향적인 느낌으로 그린다.
  - 여러 겹의 그라데이션, 외곽 조명(림 라이트), 빛 번짐(glow), 흐림 효과(blur), 원근감, 안개·구름 레이어를 사용한다.
  - 특정 제조사의 기체 형상이나 로고를 그대로 재현하지 않고, 일반적인 전기 수직이착륙기(eVTOL) 형태로 직접 디자인한다.
  - 이미지 안에는 글자를 넣지 않는다.
- **한계:** 코드로 그린 그림은 실제 사진만큼의 사실감을 내기 어렵다.
- **선택 사항: 이미지 생성 도구용 프롬프트 (참고용).** 사진 수준의 사실감이 필요하면 별도 이미지 생성 도구로 만든 뒤 `https://`로 시작하는 인터넷 주소로 삽입한다. 이 경우 사용한 도구 이름과 이용 조건을 아래 표에 기록한다.
  - 첫 화면용: `Photorealistic eVTOL air taxi hovering above a futuristic city skyline at blue hour, dark navy and cyan color palette, volumetric light, rim lighting, cinematic wide shot, shallow depth of field, ultra detailed, no text, no logos`
  - 섹션 5용: `Small eVTOL aircraft landing on a rooftop vertiport above a quiet mountain village at dawn, cool blue tones, soft fog, cinematic, ultra detailed, no text, no logos`

### 4-2. 글꼴과 라이브러리

| 자료 | 용도 | 출처 | 사용 권한 |
|---|---|---|---|
| Pretendard | 한글 본문·제목 | 공개 배포 글꼴 | 오픈 라이선스. HTML 제작 시 직접 확인 |
| Space Grotesk (선택) | 영문 헤드라인 | Google Fonts | 오픈 라이선스. HTML 제작 시 직접 확인 |
| 외부 라이브러리 | 사용하지 않음 | - | - |

글꼴이 불러와지지 않아도 기본 글꼴로 내용이 읽혀야 한다.

### 4-3. 글 내용

- 위 3-3의 소개 문장은 모두 초안이며, 사실 관계는 작성자가 검증한다. (9번 검증 방법 참고)
- 페이지 하단에 참고한 출처를 표시한다.

## 5. 완료 기준

특정 행동에 따른 기대 결과로 확인한다.

1. 페이지를 열면 어두운 배경에서 "We Fly the Dream: 우리는 도시의 지도를 바꿉니다."가 글자 단위로 나타난다.
2. 첫 화면 뒤에 UAM 기체 이미지가 배경으로 보인다.
3. 아래로 스크롤하면 섹션 2~6이 순서대로 나타나고, 섹션이 바뀔 때마다 큰 문장이 떠오르며 배경이 전환된다.
4. 섹션 3, 4, 5(수익 모델, 실생활 도움, 사회적 약자 지원)가 같은 크기와 분량으로 보인다.
5. 점 내비게이션의 세 번째 점을 누르면 수익 모델 섹션으로 이동한다.
6. 다른 파일이나 로그인 없이 열린다.
7. 휴대폰 화면 크기에서 글자가 잘리거나 좌우 스크롤이 생기지 않는다.
8. "동작 줄이기" 설정을 켜면 애니메이션 없이 내용이 바로 보인다.
9. 규제 조항이나 인증 절차 같은 세부 내용은 페이지에 나오지 않는다.

## 6. 필수 기능과 추가 기능

**필수 기능**
- 풀스크린 섹션 6개
- 글자 등장 효과
- 섹션별 배경 전환
- 점 내비게이션
- 하단 출처 표시
- 모바일 대응
- 동작 줄이기 대응

**추가 기능 (이번 구현에서는 제외, 후속 단계에서 검토)**
- 영문/국문 전환
- "관심 등록" 또는 문의 기능 (서버가 필요하므로 이번에는 제외)
- 사진 수준 이미지를 `https://` 주소로 삽입 (4-1 선택 사항)

## 7. 한계 및 비목표 (3가지)

1. 로그인, 서버, 챗봇·AI 기능, 입력 폼 제출은 구현하지 않는다.
2. 안전 규제의 세부 내용(조항, 인증 절차 등)은 다루지 않고 "안전 기준을 갖추는 단계"로만 소개한다. 규제와 상업화 현황은 실시간으로 갱신하지 않으며 작성 시점 기준이다.
3. 실제 운항 예약이나 투자 상담은 제공하지 않는다. 수익 모델은 소개 수준이며 투자 권유가 아니다.

## 8. 제약 사항

- 이번 미션의 제출물은 이 `기획서.md` 파일 1개이다. HTML 구현은 후속 미션에서 진행한다.
- 사진은 로컬 파일이 아니라 `https://`로 시작하는 인터넷 주소로 삽입한다.
- 로그인, API 키, 서버가 필요한 기능은 포함하지 않는다.

## 9. 검증 방법 (1가지)

페이지에 들어간 일정, 수치, 현황 문장(예: "한국에서는 아직 상업 운항 전")을 목록으로 뽑아, 국토교통부 등 공식 자료와 한 줄씩 대조한다. 일치하지 않거나 확인되지 않는 문장은 수정하거나 삭제하고, 대조에 쓴 자료를 페이지 하단 출처로 표시한다.
